SDLC - Software Development Lifecycle
1
Planning
(Lập Kế Hoạch)
Xác định mục tiêu, phạm vi và nguồn lực dự án.
• Phân tích yêu cầu
• Lập ngân sách
2
Design
(Thiết Kế)
Thiết kế kiến trúc hệ thống và giao diện.
• System architecture
• UI/UX mockups
3
Development
(Phát Triển)
Lập trình viên viết code xây dựng tính năng.
• Coding
• Code review
4
Testing
(Kiểm Thử)
Kiểm tra lỗi, đảm bảo chất lượng và hiệu năng.
• Unit testing
• User acceptance
5
Deployment
(Triển Khai)
Đưa sản phẩm lên môi trường production.
• Release planning
• Server setup
6
Maintenance
(Bảo Trì)
Sửa lỗi, cập nhật tính năng, hỗ trợ người dùng.
• Bug fixes
• Cập nhật
📋 Phương Pháp Phát Triển Phổ Biến
Waterfall
Tuần tự từng bước, dự án rõ ràng
Agile
Linh hoạt, lặp lại, thích nghi thay đổi
Scrum
Sprint 2-4 tuần, cập nhật hằng ngày
